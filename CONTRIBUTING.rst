============
Contributing
============

We welcome contributions to this project! Please follow the guidelines below to ensure a smooth collaboration process.

1. Fork the repository and create your branch from `main`.
2. Ensure your code follows the existing style and passes all tests.
3. Write clear and concise commit messages.
4. Submit a pull request describing your changes and the problem they solve.
5. Engage in the review process and make any requested changes.

Thank you for contributing!
