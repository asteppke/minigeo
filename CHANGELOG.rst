=========
Changelog
=========

Version 0.0.1
==============

- Basic geometry classes implemented

Version 0.1.0
==============

- Added support for 3D transformations
- Separated backend-specific implementations from core geometry classes

Version 0.2.0
==============

- API cleanup, some standardization of method names and parameters
- Animation support for geometry objects
- Improved handling of anchors for geometry placement

Version 0.4.0
==============
- Ray tracing support for scenes

Version 0.5.0
==============

- TikZ backend for rendering scenes as LaTeX ``tikzpicture``
- Animation support for scenes

Version 0.5.5
==============

- Picking points on geometry objects
- Animation support for scenes

Version 0.6.0
==============

- Numba support for faster ray tracing
- OBJ and STL file import support for geometry objects
- Polylines and curve support for geometry objects
- Mesh support for geometry objects
- LaTeX label support from matplotlib for render backends

Version 0.6.1
==============

- Improved handling of line intersections with geometry objects
- Small bug fixes

Version 0.6.2
==============

- Axes support for geometry objects
- Minimal layer support for scenes

Version 0.7.0
==============

- Misuba integration for rendering scenes

Version 0.8.0
==============

- API cleanup, e.g Plane.intersection method standardized
- Improved handling of geometry object intersections
- Axis uses origin for placement
- Explicit UTF-8 encoding for all text files
